Backup

Baixe um arquivo com todos os dados: produtos, clientes, vendas, recebimentos, gastos, usuários e o nome e logo do sistema. Guarde num pendrive, no e-mail ou na nuvem.

Restaurar backup

Substitui todos os dados atuais pelos dados de um arquivo de backup. Use também para levar os dados para outro computador.

Nome e logo do sistema

Aparece no topo do menu, na aba do navegador e no comprovante compartilhado.

As margens e o fundo branco são retirados automaticamente. Também dá para arrastar a imagem até aqui.
Como vai ficar no menu:

Só administradores podem mudar o nome e a logo.

Entrar

Este aparelho ainda não tem nenhuma conta salva. Para entrar com a conta que você já usa em outro computador ou navegador, carregue o arquivo de backup de lá (Configurações → Baixar backup). Depois é só entrar com o mesmo usuário e senha.

Para não precisar disso, use o modo Firebase: a conta e os dados ficam na nuvem e funcionam em qualquer aparelho (veja o README).
